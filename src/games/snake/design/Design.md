# Змейка: Битовый Лабиринт — утверждённый геймдизайн

## Фантазия

Змейка — это живой битовый регистр, который ползёт по расширяющейся памяти.
Игрок собирает биты, формирует целевые последовательности, применяет битовые
операции и открывает выход на следующий сектор памяти.

## Основной цикл

1. Игрок видит целевую битовую последовательность.
2. На поле находится еда в виде битов 0 и 1.
3. Змейка ест биты и записывает их в активный регистр.
4. При необходимости игрок использует токены операций.
5. Когда активный регистр совпадает с целью, последовательность завершается.
6. Завершённые последовательности открывают выход.
7. Вход в выход расширяет поле и переводит на следующий уровень.

## Активный регистр

- У уровня есть целевая последовательность длиной 4-6 бит.
- Активный регистр имеет ту же длину.
- Активный регистр отображается на первых сегментах тела от головы.
- Если змейка короче нужной длины, недостающие биты считаются нулями.
- Если змейка длиннее, лишние хвостовые сегменты не участвуют в цели.

## Запись бита

- Еда с битом 0 или 1 записывается в активный регистр.
- Новый бит становится крайним битом регистра.
- Старые биты сдвигаются.
- Змейка вырастает на один сегмент.
- Обычное движение не меняет биты.

## Целевая последовательность

- Цель уровня отображается в HUD.
- У цели есть запас записи.
- Каждый съеденный бит уменьшает запас записи.
- Если регистр совпал с целью до конца запаса — успех.
- Если запас закончился — провал.

## Успех

- Игрок получает очки.
- Последовательность засчитывается.
- Запас записи восстанавливается.
- Если нужно несколько последовательностей, генерируется следующая.
- Когда все последовательности собраны, выход открывается.

## Провал

- Игрок получает штраф.
- Текущая последовательность сбрасывается.
- Генерируется новая цель.
- Змейка может потерять один-два хвостовых сегмента.
- Провал не является мгновенной смертью.

## Битовые операции

Активное слово:

a b c d

где a — самый старый бит, d — самый новый.

| Операция |    Было |   Стало | Смысл                                         |
| -------- | ------: | ------: | --------------------------------------------- |
| <<       | a b c d | b c d 0 | сдвиг влево, старый бит теряется, справа ноль |
| >>       | a b c d | 0 a b c | сдвиг вправо, новый бит теряется, слева ноль  |
| <<<      | a b c d | b c d a | ротация влево без потери битов                |
| >>>      | a b c d | d a b c | ротация вправо без потери битов               |

## Токены операций

- Токены появляются на поле.
- Подбор токена сразу применяет операцию.
- На ранних уровнях активен один токен.
- Позже возможно два токена.
- При переходе на новый уровень токены очищаются.

## Прогрессия

- Уровень требует собрать одну или несколько последовательностей.
- Каждая собранная последовательность даёт ключ.
- Когда все ключи собраны, выход активируется.
- Вход в выход расширяет поле.
- После расширения:
  - уровень повышается;
  - еда и токены очищаются;
  - генерируется новая цель;
  - сложность растёт.

## Рост поля

- Размер клетки не меняется.
- Поле растёт.
- Холст растёт вместе с полем.
- Камера не уменьшает масштаб.
- Есть максимальный размер поля.
- После достижения максимума поле больше не растёт, но сложность продолжает расти.

## Смерть

- Столкновение со стеной — смерть.
- Столкновение с собственным телом — смерть.

## Очки

- Еда: маленькие очки.
- Последовательность: крупные очки.
- Открытие выхода: бонус.
- Вход в выход: бонус.
- Провал последовательности: штраф.
- Счёт не уходит ниже нуля.

## Интерфейс

Игрок должен видеть:

- счёт;
- уровень;
- целевую последовательность;
- активный регистр;
- запас записи;
- состояние выхода.

## Состояния

- MENU;
- PLAYING;
- PAUSED;
- GAME_OVER.

## Кнопки

- START;
- PAUSE / RESUME;
- RESTART;
- MUTE.

## Визуальный стиль

- Тёмный фон.
- Мягкие неоновые акценты.
- Бит 0 — холодный цвет.
- Бит 1 — тёплый цвет.
- Голова змейки ярче тела.
- Выход отличается цветом и формой.
- Токены операций читаются отдельно.
